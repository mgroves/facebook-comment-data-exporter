Facebook Comment Data Exporter

Free, local, no API key, no Facebook password to share, no subscription.

1. Install in Brave/Chrome browser (one-time)

Make sure your bookmarks bar is visible. Press Ctrl + Shift + B if it is hidden.

Drag this blue button onto your bookmarks bar:

FB Comment Exporter ⇧ drag to bookmarks bar

If dragging fails, click below and create a bookmark manually.

Manual setup: Right-click the bookmarks bar → Add page → name it FB Comment Exporter → paste the copied text into the URL field → Save. Don't paste it into Facebook's address bar.

2. Export a Facebook post

  1. Log into Facebook normally in your browser and open the post you want. Click its date/time if you need to open the post itself.
  2. Open the comments if they are collapsed.
  3. Click FB Comment Exporter on your bookmarks bar. It automatically switches to All comments, expands replies and scrolls to load more.
  4. Watch the small box at the top right of Facebook. Once it finishes, compare the captured count against Facebook's displayed count. Click Load / resume if it is short.
  5. Click Download CSV and Download JSON. The files will be in your Downloads folder.

What is exported: full visible comment text; name; profile and comment URLs; original comment and parent IDs; reply depth; date labels and parseable/estimated timestamps; reactions and reply counts where visible; edit indicators; media and link URLs; image alt text; and extraction metadata.

What “all” means here

This retrieves all comments Facebook makes available to your logged-in browser, not content hidden, removed or restricted by Facebook. The displayed count may include comments you cannot access. The tool explicitly reports a shortfall instead of claiming success.

Edit status: true means a visible Edited marker was detected. null means unknown, not confirmed unedited. Facebook does not consistently reveal edit history or exact creation times in its public webpage.

Privacy: all processing happens inside your browser. This tool doesn't upload data to any service.

If Facebook changes its interface, this may need updates. Open-source scrolling and DOM approach informed by Roei's Facebook Comment Explorer (MIT licensed). A fallback Chrome extension is included in the ZIP package.
