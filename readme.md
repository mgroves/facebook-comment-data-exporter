# Facebook Comment Exporter

A lightweight browser bookmarklet for exporting comments and replies from a Facebook post as CSV and JSON files, entirely in the browser.

## Files

- `Facebook-Comment-Exporter.html` — standalone install page and bookmarklet

## Usage

1. Open `Facebook-Comment-Exporter.html` in Brave or Chrome.
2. Drag the blue bookmark button onto your bookmarks bar.
3. Open the Facebook post you want to inspect.
4. Click the bookmark to load the export panel.
5. Use the panel to load/resume collection and download CSV or JSON output.

## Notes

- No API key, password, or server is required.
- Data stays local to your browser.
- This tool is intended for personal/export use and follows the platform's terms of service.
